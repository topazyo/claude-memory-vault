## Wrap-up Summary

Produce these sections:

- **Task objective**
- **Key changes**
- **Decisions made** — flag any that are candidates for a long-term standard
- **Open questions / follow-ups**
- **What this session could not determine** — gaps, unverified claims, tools that failed.
  `none` is a valid answer. An unstated gap is indistinguishable from completeness, and a
  summary that reads as complete gets acted on as complete.
- **Links** to the relevant files and vault notes

Make sure the result can be pasted into both:

1. A medium-term log in `20-projects/_logs/`.
2. An auto-memory topic file (e.g. `debugging.md`, `api-conventions.md`).
